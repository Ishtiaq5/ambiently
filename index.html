About this build

Ambiently is a single-page experiment in browser-native audio. Each ambience is synthesised from filtered noise with crackle bursts and slow modulation layered on top — so the mix never repeats itself the same way twice.

Vanilla HTML, CSS and JavaScript. No frameworks, no CDN, no backend.
